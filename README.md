# 量潮学习管理日志

量潮学习管理（quanttide-learn）领域的学习管理日志——记录教学过程、学员成长与交流沉淀。

## 结构

一个学习者一个文件夹，按日期记日志（学员与自助学习者统一收录，如 Jerry、iGuo）：

```
journal/
├── Jerry/              # 学员（Jerry）
│   └── 2026-08-30.md
└── iGuo/               # 自助学习者（iGuo）
    └── 2026-08-30.md
```

## 约定

- 日志来源：教学交流、任务交付记录
- 格式：按议题分组整理（不逐条罗列消息），保留关键原话，附教学观察
- 日志是结构化沉淀，后续修订以最新版本为准
